常见问题

Windows 提示未知发布者怎么办

这是因为当前安装包尚未配置代码签名证书。请只从本页面下载，并核对页面显示的 SHA256。

为什么安装包被浏览器提醒

新发布的 Windows 安装包可能因为下载量较低被浏览器提示。请确认下载域名是 download.minipet.versecraft.cn。

如何退出桌宠

右键桌宠或托盘图标，选择退出。

如何切换自己的模型

打开桌宠设置，进入高级，选择使用自己的模型并填写 Base URL、Model 和 API Key。

如何反馈问题

请通过项目 GitHub issue 或下载页后续公布的反馈入口提交问题。

隐私政策

MiniPet 默认使用匿名设备 ID 创建额度账户，不采集真实姓名、手机号或邮箱。默认托管模式下，对话请求会发送到 MiniPet 后端用于完成 AI 回复和额度统计。

用户主动选择文件总结或高级能力时，相关内容只会在完成该请求所需范围内使用。BYOK 模式下，用户自己的 API Key 仅保存在本机安全存储中。

用户协议

MiniPet 提供学习、办公辅助能力。用户应避免提交违法、侵权或高风险自动化请求。高危文件、支付、消息发送等操作需要用户确认。

服务可能因为网络、模型供应商、额度或维护原因暂时不可用。请在重要工作中自行确认 AI 输出结果。
