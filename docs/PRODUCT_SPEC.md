# MiniPet 产品说明

MiniPet OpenClaw Companion 是 “桌宠 + OpenClaw 可视化控制台” MVP。

## 定位

- 面向中文新手用户
- 简约二次元、低打扰、浅色优先
- OpenClaw Gateway 的桌面入口
- 不是实际执行器，不直接绕过权限执行系统操作

## MVP 能力

- 首次启动引导
- 可拖拽、可置顶、可隐藏桌宠窗口
- 自动扫描并手动映射桌宠素材
- OpenClaw Gateway 连接状态
- Demo Mode / Local Chat fallback
- 普通对话
- 联网搜索快捷 prompt
- PPT 生成快捷 prompt
- 浏览器控制快捷 prompt
- 文件处理快捷 prompt
- 任务时间线和请求级 localRequestId
- 权限模式和审计日志
- 技能推荐面板

## 非目标

- 不自动安装 OpenClaw
- 不自动安装第三方 skill
- 不执行 shell
- 不默认读取全盘
- 不在 renderer 中保存或读取密钥
