# 用户指南

## 第一次打开

1. 启动 `npm run dev`。
2. 在欢迎页确认 MiniPet 的用途。
3. 检查素材目录，默认 `D:\minipet\design\one`。
4. 填写 OpenClaw Gateway 地址。
5. 如需普通聊天，填写大模型 API Key。
6. 保持默认安全模式。

## 桌宠操作

- 单击：打开快捷按钮
- 双击：打开命令面板
- 右键：打开设置
- 托盘：隐藏或恢复窗口
- 设置页：调整缩放、置顶、鼠标穿透

## OpenClaw 未连接

你仍可以打开 MiniPet 和普通聊天。联网搜索、PPT、浏览器和文件处理需要连接 OpenClaw Gateway。

## 安全建议

第一次使用建议保持安全模式。只有在理解风险时，才启用完全访问模式。安装第三方技能前，请确认来源可信。
